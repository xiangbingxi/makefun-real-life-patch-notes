One-line patch note for a bug in real life, 160 characters max.

Competition: https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d

## Entry

> Laundry v2.1: Socks now disappear in pairs so you can stop keeping the survivor around for closure.

99 characters, within the 160-character limit.

## How it works

Run `python3 main.py`. It writes the entry text, exactly as above, to
`/output/entry.txt` — UTF-8, no trailing newline, no external files, no
network. After writing, it reads the file back and exits with an error if
the content differs from the entry by even one character.
